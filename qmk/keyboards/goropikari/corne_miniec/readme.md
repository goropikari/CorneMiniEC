# Corne Miniec v0.2

左右それぞれに Seeed Studio XIAO RP2040 を載せた36キーの静電容量無接点キーボードです。miniEC の7種類のキーマップを収録しています。すべて Vial で編集できます。

[Vial ファームウェアのビルド・書き込み手順](../../../README.md)

## 静電容量スキャン

各側に3行×6列を割り当て、列は EC モジュールの S5、S6、S4、S1、S2、S3 の順で読み取ります。ADC は12ビットです。

起動時に各キーの測定値が安定するまで読み取り、観測した最小値を未押下時の基準値にします。押下・解放は、それぞれの基準値に `config.h` のオフセットを足した値で判定します。初期値の押下560・解放480は、miniEC の8ビット相当のオフセット35・30を12ビットのスケールに換算したものです。

使用中は未押下の測定値をローパスフィルターに通し、10秒ごとに直近5回の推定値の平均で基準値を更新します。Bootmagic のスキャンでは、キャリブレーション前に KMK 版と同じ絶対しきい値を使います。
