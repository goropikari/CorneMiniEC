# Corne Miniec v0.2

左右それぞれに Seeed Studio XIAO RP2040 を載せた36キーの静電容量無接点キーボードです。miniEC の7種類のキーマップを収録しています。すべて Vial で編集できます。

[Vial ファームウェアのビルド・書き込み手順](../../../README.md)

## 静電容量スキャン

各側に3行×6列を割り当て、列は EC モジュールの S5、S6、S4、S1、S2、S3 の順で読み取ります。ADC は12ビットで、`config.h` の押下・解放しきい値は KMK 版の 0.7 V・0.6 V を3.3 V基準で換算した初期値です。連続押下の判定は QMK のタップ・ホールド処理に従います。
